## Pregunta 1

¿Qué es el ataque de "Cross Site Scripting" (XSS) y cómo podría prevenirse? Describa un escenario en el cual este tipo de ataque podría ser especialmente peligroso. Para responder esta pregunta, puede basarse en [este articulo de la OWASP](https://owasp.org/www-community/attacks/xss/).

**Respuesta**:

El ataque Cross Site Scripting (XSS) es un tipo de ataque que vulnera la seguridad de los usuarios en una página web segura o no maligna, mediante la inyección de un código malicioso a traves de este. Esto ocurre cuando la página pide ingresar datos y no los gestiona correctamente, permitiendo que se introduzca un script que puede robar cookies, tokens u otra información importante. Existen tres tipos de XSS: el reflejado, donde el script se muestra al usuario como un mensaje o error para que haga click; el almacenado, donde la inyección queda guardada en el servidor y se ejecuta al ingresar a la página; y el ciego, que es persistente y se ejecuta, por ejemplo, cuando un formulario es revisado en el backend.

No hay una única forma de prevenir estos ataques, pero se pueden aplicar medidas para prevenirlos como validar mejor los datos ingresados con JavaScript, desactivar HTTP TRACE, codificar variables en HTML y sanitizar el contenido. Además, algunos frameworks modernos ya incluyen protecciones contra este tipo de ataques, lo que ayuda a reducir los riesgos.

Este ataque puede ser peligrosos si se roban datos bancarios o si se extrae información sensible de una empresa, como los id de los empleados, lo que podría permitir el acceso a servidores importantes o a sus correos para algún uso indebido.


## Pregunta 2
Como se mencionó en auxiliar, existen varias herramientas que se pueden utilizar para programar aplicaciones web más complejas que las que hemos visto en el curso. Esta pregunta busca que ud. investigue 3 librerías de javascript o *frameworks* de front-end y describa sus principales características, ventajas, desventajas y ejemplos de uso. Finalmente, indique cuál de las tecnologías presentadas utilizaria para implementar su página web personal y por qué.

**Nota:** Se espera que ud. escriba un breve resumen de cada tecnología, seguido de al menos 2 ventajas y 2 desventajas de cada una.

**Respuesta**:

React es una biblioteca de JavaScript que permite crear interfaces de usuario; se caracteriza por el uso de un flujo de datos en una dirección, por lo que los cambios en los códigos van jerárquicamente (si está abajo no influyen en los de arriba).
Como ventaja seria que permite crear componentes reutilizables y que tiene una gran comunidad para dar soluciones si me ocurre un problema.
Una desventaja seria que es difícil de aprender a usar y que tambien puede volverse compleja al escalar proyectos grandes.
(https://www.ionos.com/es-us/digitalguide/paginas-web/desarrollo-web/frameworks-javascript-y-librerias-populares/)

jQuery es una de las librerías más populares de JavaScript, tiene programación de estilos muy similares a CSS; se pueden manipular distintos elementos a la vez con una línea de código, y lo más destacable sería la selección de plugins, como los formularios de suscripción y anuncios emergentes, que están listos para usar con un par de comandos.
Como ventaja es fácil de aprender y permite reducir líneas de código.
Como desventaja puede ser de carga lenta y bajo rendimiento del código, otra desventaja es el poco control de la página web al estar usando el código de alguien más.
(https://ebac.mx/blog/que-es-jquery)

Gatsby es un framework de código abierto basado en React que genera sitios estáticos; busca integrar las mejores prácticas a los sitios web, se caracteriza por maximizar la velocidad de los sitios usando técnicas como la división automática de código, inlining de estilos y optimización de imágenes. Usa virtual DOM y Hot Reloading.
Como ventaja genera sitios rápidos y que mejora el SEO (Search Engine Optimization),es decir, Google ayuda a tu sitio a estar mejor posicionado.
Como desventaja seria que la configuración inicial es compleja y la dependencia de plugins para muchas funciones.
(https://bambu-mobile.com/los-mejores-frameworks-de-javascript/)


Usaria React para mi pagina web para tener mas control de cada parte del sitio web y facilitar las interfaces, por ejemplo me permite crear sitios interactivos y dinámicos sin tener que recargar la página al agregar pop-ups, formularios que reaccionan cuando el usuario escribe, botones que cambian el contenido, o temas oscuros y claros. Todo eso se puede manejar con componentes que responden al estado de la página, haciendo que se vea más profesional y amigable para el usuario.
